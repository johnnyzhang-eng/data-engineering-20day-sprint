## 一天的流程

```
早上   陪练开场：列出今天到期的复测题（D+2、D+7），先闭卷做变式
上午   编码主线（SQL；过了 D3 门槛后加 Python）：讲解 → 预测 → 本人先写 → 运行 → 讲为什么 → 变式
下午   概念主线：读讲义 → 读原文（阅读循环）→ 用自己的话口述 → 追问
       项目防守：按事实卡口述一个简历条目，扛三层追问；D5 起穿插代码考古
收尾   面试条件小测（无 AI、限时）→ 判卷 → 写当天记录 → 提交
```

## 阅读循环（读原文）

讲义是地图，原著和官方文档是实地。每次只带一个问题去读，范围控制在一节或一篇。

1. **读前**：写下这个问题的答案，三行以内，不会就写"不知道"。
2. **读**：只读指定的小节。最多记三条结论，每条写明出处，以及是原文直接说的还是自己推断的。单段卡住超过 10 分钟就停下，把问题带回来。
3. **合上书讲**：60–90 秒，讲给自己听或用语音转文字。
4. **发回执**给当天的陪练：

```text
【读了什么】资料、章节或小标题
【读前答案】一两句
【合上书讲】150–300 字，或 90 秒语音转文字
【我的例子和边界】一个原文没有的例子；什么时候不成立
【还不懂】最多一个问题
```

5. **陪练回应**：把本人的说法逐句标成"符合原文 / 原文没说，是推断 / 缺条件 / 和原文冲突"；先给方向提示；出一道迁移题。
6. **概念卡**：本人自己写 5 栏：是什么 / 为什么 / 一个例子 / 什么时候不成立 / 复测记录。D+2、D+7 换一个条件复测。

读完原文不算掌握。掌握仍按下面的 L0 + P 等级判断。

## 代码考古（读自己的代码，D5 起）

从 M8 项目防守的时间里出，D3 门槛没过就顺延。只把 SQL 抽出来，在练习库里用合成数据运行，不运行项目代码本身。由公司代码得出的笔记只放 `private/code-study/`，不写进 `daily/` 或任何公开目录。

一次约 45 分钟：

1. **选一段**：一条 SQL，或一个转换函数。
2. **预测**：只看文件名、函数名、注释，写下"它在算什么"；再预测空输入、重复键时的结果。
3. **追数据流**：输入表 → 中间几步 → 输出表，画出来。
4. **闭卷重写**：合上代码，在练习库里写出做同样事情的 SQL，记求助级别。
5. **运行对照**：比较预测、自己的首稿和原代码，找出差异和错因；原代码有没有问题。
6. **变式和口述**：改一个条件（数据量大 10 倍、重跑一次），60 秒讲清"为什么这样写"。

| 天 | 用时 | 内容 |
|---|---|---|
| D5 | 45 分钟 | 一条短 SQL，对应粒度和 JOIN |
| D9 | 60 分钟 | 一个转换步骤，对应幂等和重跑 |
| D13 | 45 分钟 | 没读过的 SQL 或 Python 片段 |
| D18 | 60 分钟 | 新片段，兼作项目防守验收 |

**目标样本**：3 条难度不同的真实 SQL（`private/code-study/target-samples.md`），D1、D7、D14 各花 5 分钟读一遍，写下"现在能看懂百分之多少、卡在哪"。只记录进步，不算学习时间。

## 复盘节奏：记录怎样回到计划

材料不一次生成完，因为门槛结果会改变后面的安排（比如 D3 没过，就推迟 Python）。本人在下面这些天的晚上告诉 Opus"复盘第 N 天"，Opus 读 `daily/` 和 `private/progress/attempts.jsonl`，再做表里的事。

| 复盘点 | 看什么 | 要下发的材料 |
|---|---|---|
| D2 晚 | D1–D2 的首稿、求助级别、卡点 | D4–D5 的 SQL 材料（Codex CLI） |
| D3 晚 | D3 门槛 | 过了：D4 起加 Python（Codex CLI 出 Python 材料）。没过：D4 改为补 SQL |
| D5 晚 | M3 口述、第一次代码考古 | D6–D7 的材料；审 M5–M7 讲义 |
| D6 晚 | D6 门槛 | D8–D9 的材料 |
| D7 | 本人花 15 分钟复盘：哪些任务还依赖 AI，哪类错误反复出现；下一周只改一项做法 | 简历 v1；第二周安排定稿 |
| D9 晚 | M5、M7 口述，D10 模拟面试准备情况 | D10–D12 的材料 |
| D12 晚 | 第二周汇总 | D13–D15 的材料；二面与 HR 模拟题 |
| D15 晚 | 弱项清单 | D16–D18 的验收题 |
| D18 晚 | 各项验收结果 | D19–D20 的终测安排 |

复盘点没有按时进行时，陪练照常按 `docs/days/` 已有的材料推进；材料用完就先做复测和变式，不自己编新的课程内容。

## 记两样东西

- **求助级别** L0–L3：L0 无帮助；L1 方向提示；L2 关键步骤；L3 完整示范。
- **表现等级** P0–P3：
  - P0：做不出或结果错；
  - P1：结果对；
  - P2：能讲清边界和为什么；
  - P3：能比较方案、迁移到新场景。

只有 L0 下完成的题，才算独立的 P1–P3。
