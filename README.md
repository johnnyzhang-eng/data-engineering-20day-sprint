# data-engineering-20day-sprint

用 20 天，把数据工程实习面试需要的基础，从"讲不出、写不出"补到"能亲手写出来、能讲清为什么"。

**状态**：准备中（私有）。目标、方法和计划确定后补充。

## 原则

- 记录真实作答，包括错误、求助程度和复测结果。
- 只用公开资料或合成数据，不包含任何公司内部代码或数据。
- 用模拟面试衡量进步，而不是用学了多少内容。

## 目录

| 目录 | 内容 |
|---|---|
| `docs/` | 方法论、目标、计划 |
| `daily/` | 每日记录 |
| `exercises/` | 练习题与作答 |
| `interviews/` | 模拟面试 |
| `research/` | 岗位与面经统计 |
| `tools/` | 工具脚本 |
