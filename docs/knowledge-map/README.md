## 从哪里开始

- **今天在练 SQL**：先从一张表的筛选和汇总入手。开始学多表查询时，用[订单金额示例](order-metrics.md)看懂连接为什么会改变指标。
- **想看整个岗位**：先看[一条订单怎样变成报表](../notes/m0-overview.md)，再对照[岗位技能统计](../../research/jd-stats.md)与日期、样本不同的[后续岗位记录](../../research/targets-summary.md)。
- **想弄清 agent**：从[订单例子里的三种执行方式](order-metrics.md#从模型到-agent)切入，再按基础、原始研究、工程实践扩展。时间线放在 AI 路径，学习顺序根据先修关系决定。

## 怎样逐项补全

每个主题回答五个问题：解决什么问题、受到哪条岗位原文或技术来源支持、先懂什么、用什么材料学、怎样独立验证。岗位硬要求、工作职责、面试观察和教材推导分别注明。

视频写到具体讲次或章节，说明要看懂的机制。书和文档写到对应小节。陪练着重预测和反馈，综合练习保留独立的预期结果。选片时复用现有资源，并检查材料实际讲了什么。

补充一批材料后，用留出的 JD 检查遗漏的任务与深度；用可运行的样例核验答案和失败条件。第一版是课程索引与覆盖表，各主题仍需逐条补证。
