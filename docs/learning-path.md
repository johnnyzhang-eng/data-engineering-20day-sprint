# 学习路径：怎样每天运转

计划定了"学什么"，本文件说明"每天怎样学、练、测、记"。

## 一天的流程

```
早上   Codex 陪练开场：列出今天到期的错题（D+2、D+7），先闭卷复测
上午   编码主线（SQL；过了 D3 门槛后加 Python）：讲解 → 预测 → 本人先写 → 运行 → 讲为什么 → 变式
下午   概念主线（数仓、场景、Spark/Hive、ClickHouse、ETL）：读讲义 → 用自己的话口述 → 追问
       项目防守：按事实卡口述一个简历条目，扛三层追问
收尾   面试条件小测（无 AI、限时）→ 判卷 → 写当天记录 → 提交
```

## 谁做什么

| 角色 | 职责 |
|---|---|
| 本人 | 在 VS Code 里写代码，口述，拍板 |
| Codex 桌面版 | 每日陪练：出题、判卷、按规则分级给提示、写记录 |
| Codex CLI | 提前 2–3 天生成练习材料：数据、题目、答案、小测；维护复测清单脚本 |
| Kimi | 写概念讲义和口述追问题（挂到本人项目上）；在中期调整时独立挑错 |
| Opus | 课程骨架；每 2–3 天看记录，按门槛调整后面的安排；最后整合 |

## 材料按"滚动"方式生成

不一次性生成 20 天的材料，因为门槛结果会改变后面的安排（比如 D3 没过，就推迟 Python）。
每晚看当天的记录，再生成或调整后面 2–3 天的材料。

## 文件布局

| 位置 | 内容 | 公开与否 |
|---|---|---|
| `docs/days/dNN.md` | 第 NN 天的目标、主题、练习范围 | 公开 |
| `exercises/<模块>/dNN/` | 题目和本人作答 | 公开（合成数据） |
| `daily/YYYY-MM-DD.md` | 每天的记录：首稿、求助级别、表现等级、错因 | 公开前审查 |
| `private/answer-keys/`、`private/quizzes/` | 答案和小测 | 不公开，本人不看 |
| `private/progress/attempts.jsonl` | 每道题一行，机器可读，用来算复测日期和统计 | 不公开 |
| `private/fact-cards/` | 简历事实卡 | 不公开 |
| `private/applications.csv` | 岗位资格表与投递台账 | 不公开 |

## 记两样东西

- **求助级别** L0–L3：L0 无帮助；L1 方向提示；L2 关键步骤；L3 完整示范。
- **表现等级** P0–P3：
  - P0：做不出或结果错；
  - P1：结果对；
  - P2：能讲清边界和为什么；
  - P3：能比较方案、迁移到新场景。

只有 L0 下完成的题，才算独立的 P1–P3。
