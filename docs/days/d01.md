# D1｜单表查询、排序、聚合与 NULL

日期：**2026-10-31**。SQL、Python 都从零起步；今天只练 SQL。

## 今天的目标

- 能按需求选择输出列，组合 WHERE 条件，正确区分 NULL 和零。
- 能用 ORDER BY 明确顺序、用 LIMIT 截取、用 DISTINCT 对输出组合去重。
- 能说清 COUNT(*)、COUNT(列)、SUM、AVG 的输入和分母，并预测空输入或全 NULL 的结果。
